## 📌 О проекте

**Makoll RemoteBot** — утилита для удалённого управления собственным Windows-компьютером через Telegram и VK.

Приложение работает в фоновом режиме и принимает команды от разрешённых пользователей.

Проект рассчитан на простую установку: конечному пользователю не требуется устанавливать Python или разбираться с исходным кодом.

После первого запуска открывается мастер настройки, где необходимо выбрать используемые платформы и указать соответствующие данные подключения.

---

## ✨ Возможности

На данный момент доступны:

- 📸 Получение скриншота рабочего стола
- 🔒 Блокировка компьютера
- 🔄 Перезагрузка компьютера
- ⏻ Выключение компьютера
- ℹ️ Информация о Makoll RemoteBot
- 🎛️ Быстрые кнопки управления
- 🔐 Ограничение доступа по ID пользователя
- 🟢 Поддержка Telegram
- 🟣 Поддержка VK
- 🚀 Автозапуск вместе с Windows
- 🖥️ Работа в фоновом режиме
- 🔧 Настройка через графический интерфейс
- 🛡️ Защита от запуска нескольких экземпляров приложения
